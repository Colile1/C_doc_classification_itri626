# docs/

Project documents that are not the report. They record the process behind the results.

| File | Purpose |
|------|---------|
| `compute-plan.md` | Where each part of the work runs, why, and what the fallbacks are |
| `dataset-card.md` | Source, licence, usage conditions, class definitions, counts before and after cleaning |
| `experiment-log.md` | One row per training run: config, commit, environment, result, what was learned |

A reader new to the project can read `experiment-log.md` and know exactly what was trained and how.
