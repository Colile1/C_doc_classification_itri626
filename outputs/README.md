# outputs/

Everything generated by a run. Nothing here is edited by hand, and
nothing here is a source of truth: deleting the whole folder and re-running
must restore it.

| Path | Contents | Committed? |
|------|----------|-----------|
| `metrics/` | Per-run history JSON, per-model metric tables, the three-model comparison table | Yes (small) |
| `figures/` | Confusion matrices, learning curves, class examples, error samples | Yes (the ones the report uses) |
| `checkpoints/` | Model weights | No, too large. Access instructions go in the root README |
| `logs/` | Run logs, including the environment record: library versions, device, seed | Yes |

Each run writes into a subfolder named for its config and commit, so two
runs of the same model never overwrite each other and the report can cite
exactly which one produced a figure.

Done when: every figure in the report exists here and can be regenerated
by naming its run.
