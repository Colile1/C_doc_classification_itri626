Three model families on one leakage-free split

Checking...

Each model assigns a scanned page to one of eight document types from its appearance alone. All three were trained on the same pages and scored once on the same held-out pages, so their numbers compare directly.

Where to look

Every figure on these pages is read from the committed split and metric files.

  • Try the classifier: upload a page and see the scores for each class.
  • Dataset: how many pages of each class went into training, validation and test.
  • Results: the comparison table, learning curves and per-class scores.
  • Model results: each model's confusion matrix, errors and assessment.
  • Model comparison: accuracy against cost, and which model wins each class.
